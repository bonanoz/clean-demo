# clean.cars

Демо-лендинг автомойки и детейлинга на русском: первый экран с машиной поверх заголовка, услуги с ценами, калькулятор, слайдер «до/после», отзывы, частые вопросы и форма записи. Структура и палитра взяты с референса clean.cars, приём первого экрана — с лендинга Breezy (оба лежат в `docs/specs/carwash-demo/`).

Сайт демонстрационный. Телефон `+7 (900) 000-00-00`, почта `hello@cleancars.example`, адрес «ул. Примерная, 1», цены, отзывы и цифра «1 500 владельцев» выдуманы. Форма записи проверяет поля в браузере и показывает подтверждение, но никуда ничего не отправляет.

## Запуск

Нужен Node.js 22.12 или новее (этого требует vitest).

```bash
npm ci
npm run dev
```

`.npmrc` включает `legacy-peer-deps`: у shadcn и `@vitejs/plugin-react` расходятся необязательные peer-зависимости Babel, без флага `npm ci` падает.

Остальные команды:

```bash
npm test          # vitest, тесты по критериям из SPEC
npm run build     # проверка типов и сборка в dist/
npm run preview   # раздать dist/ локально
```

`npm run build` собирает страницу дважды: обычную сборку для браузера и серверную из `src/entry-server.tsx`. Затем `scripts/prerender.mjs` вписывает готовую разметку и CSS в `dist/index.html`, поэтому первый экран рисуется до загрузки JS, а React потом только оживляет страницу (`hydrateRoot` в `src/main.tsx`). Отсюда правило для компонентов: при первом рендере не читать `window`, текущую дату и другое, что в браузере отличается от сборки. Такие значения считаются в `useEffect`.

## Как устроено

- Vite, React 19, TypeScript, Tailwind 4. Из shadcn остались конфиг и `button`, свои компоненты собраны на Tailwind. Библиотек анимации нет.
- `src/index.css` — вся дизайн-система: палитра, шрифты, шкала текста, радиусы, кривые и длительности. Под новый референс правится этот файл, секции берут значения только через токены и утилиты (`bg-ink-2`, `text-fog`, `type-h2`, `rounded-card`).
- `src/sections/` — секции страницы, `src/components/kit/` — общие кирпичи (карточка с вырезом, моно-метка, фото, появление при прокрутке, заголовок по словам), `src/data/` — тексты, услуги, цены, отзывы и вопросы, `src/lib/` — расчёт цены, проверка формы, форматирование рублей и русская типографика (`typo()` ставит неразрывные пробелы после коротких слов, перед тире и после чисел).
- Движение — на CSS: переходы, `@starting-style`, анимации, привязанные к прокрутке (`animation-timeline`), и Web Animations API для подсказки у слайдера. Анимируются только `transform`, `opacity` и `clip-path`. При `prefers-reduced-motion: reduce` остаются короткие переходы прозрачности.
- Шрифты Unbounded, Geist и Geist Mono лежат в `public/fonts/`: по два вариативных woff2 на гарнитуру (кириллица и латиница). Для каждой задан запасной шрифт с подогнанными метриками, чтобы при загрузке текст не прыгал.
- Фото в `public/images/` — AVIF и WebP в трёх ширинах (640, 1024, 1600), размеры для разметки — в `src/data/images.ts`.

Спецификация, решения и журнал работы — `docs/specs/carwash-demo/SPEC.md`.

## Вес и скорость

Замер от 31 октября 2026 года: `npm run build`, затем Lighthouse 12 в режиме mobile на `npm run preview`.

| Что | Сейчас | Бюджет |
|---|---|---|
| JS (gzip) | 94,8 КБ | 100 КБ |
| CSS (gzip, встроен в HTML) | 10,4 КБ | 20 КБ |
| Шрифты, 6 файлов | 159 КБ | 160 КБ |
| Машина на первом экране, `hero-car-1024.avif` | 24 КБ | 120 КБ |
| Performance, замедление DevTools | 93 (FCP 1,3 с, LCP 1,6 с, TBT 300 мс, CLS 0) | 90 |
| Performance, моделирование по умолчанию | 88 (FCP 2,4 с, LCP 3,4 с) | 90 |
| Accessibility, Best Practices, SEO | 100, 100, 100 | 95, 95, 90 |

Режимы расходятся, потому что модель Lighthouse относит к первому кадру всё, что запрошено до него: шесть шрифтов, JS и ленивые фото бенто. При настоящем замедлении сети и CPU первый кадр приходит через 1,3 с.
